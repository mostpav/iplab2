Лабораторна робота №2 — завдання для самоперевірки
Тема: Особливості виконання операцій та операторів у JavaScript. Типи даних. Приведення типів.

2.1. Результати виконання

Початково a = 2, b = 3.
1) c = ++a; alert(c)  → 3
2) d = b++; alert(d)  → 3
3) c = (2 + ++a); alert(c) → 6
4) d = (2 + b++); alert(d) → 6
5) alert(a) → 4
6) alert(b) → 5

Префіксний інкремент спочатку збільшує значення, а постфіксний повертає старе значення і збільшує змінну після цього.

2.2. Результат

a = 2; a *= 2 присвоює a значення 4.
x = 1 + 4 = 5.
Отже, x = 5.

2.3. Значення та пояснення

1) alert(null || 2 || undefined) → 2
2) alert(alert(1) || 2 || alert(3)) → спочатку показує 1, потім 2. alert(1) повертає undefined (хибне значення), тому || переходить до 2; alert(3) не виконується.
3) alert(1 && null && 2) → null
4) alert(alert(1) && alert(2)) → спочатку показує 1, потім зовнішній alert показує undefined. alert(2) не виконується, бо alert(1) повертає undefined, яке є хибним.
5) alert(null || 2 && 3 || 4) → 3 (&& має вищий пріоритет за ||)
6) if (-1 || 0) alert('первое') → показує «первое»
7) if (-1 && 0) alert('второе') → не показує повідомлення
8) if (null || -1 && 1) alert('третье') → показує «третье»

2.4. Значення та типи

Вираз                     Результат          Тип
"" + 1 + 0                "10"               string
"" - 1 + 0                -1                 number
true + false              1                  number
6 / "3"                   2                  number
"2" * "3"                 6                  number
4 + 5 + "px"              "9px"              string
"$" + 4 + 5               "$45"              string
"4" - 2                   2                  number
"4px" - 2                 NaN                number
7 / 0                     Infinity           number
" -9\n" + 5               " -9\n5"            string
" -9\n" - 5               -14                number
5 && 2                    2                  number
2 && 5                    5                  number
5 || 0                    5                  number
0 || 5                    5                  number
null + 1                  1                  number
undefined + 1             NaN                number
null == "\n0\n"           true               boolean
+null == +"\n0\n"         true               boolean

У логічних операторів результатом є один з операндів, а не обов’язково boolean. При арифметичних операціях рядки, які можна перетворити на числа, приводяться до number. Рядок з нечисловими символами дає NaN.
